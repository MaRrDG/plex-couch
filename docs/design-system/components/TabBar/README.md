The bottom tab bar with the app's three destinations: Acasă, Filme, PC.

- The consumer provides the selected tab. Icons are the system's home, film and pc glyphs; labels in `tab`.
- Selected: icon and label in `accent`. Others: `muted`. Background `bg` with a `line` hairline on top, plus the bottom safe-area inset.
- Always three tabs, always this order. Never hide it, and never add a badge count.
- Do not use it for in-page filters; that is `SegmentedControl`.
